SMMRM Verification Package

This package was generated by the SMMRM Certificate Package Generator.

Files:
- index.html        Public verification page
- styles.css        Responsive visual design
- script.js         Data rendering + automatic validity countdown
- data.js           Certificate data used by the page (offline-safe)
- data.json         Certificate data in JSON format for audit/import
- assets/           Logo, favicon, ship and footer artwork

Usage:
1. Keep all files/folders together.
2. Open index.html in a browser.
3. The remaining-validity counter is calculated automatically from validUntil.
4. Empty fields are displayed as 'NA'.

Do not manually edit the countdown text. Change validUntil in the generator and regenerate the package.
